ติดตั้ง LINE MR เรียบร้อยแล้ว

ต่อจากนี้ให้เปิด LINE ผ่าน LINE MR ทุกครั้ง (Applications > LINE MR) LINE MR จะเปิด LINE พร้อมส่วนเสริม VoiceOver ถ้าเปิด LINE โดยตรง ส่วนเสริมจะไม่ทำงาน

  • แนะนำ: วาง LINE MR ไว้ใน Dock แทน LINE
  • ถ้า LINE เปิดอยู่แล้ว LINE MR จะถามก่อนแล้วเปิด LINE ใหม่ให้
  • ครั้งแรก macOS อาจบล็อก LINE MR ดูวิธีกด "Open Anyway" ในไฟล์อ่านก่อนติดตั้งบน DMG หรือ README ของโครงการ
