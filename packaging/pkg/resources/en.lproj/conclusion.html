LINE MR is installed

From now on, open LINE through LINE MR (Applications > LINE MR). LINE MR opens LINE with VoiceOver support. If you open LINE directly, VoiceOver support is not active.

  • Tip: keep LINE MR in the Dock instead of LINE.
  • If LINE is already open, LINE MR asks to restart it.
  • The first time, macOS may block LINE MR. See the Read Me on the disk image or the project's README for "Open Anyway".
